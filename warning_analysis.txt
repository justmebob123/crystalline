## Strategy:

Based on the codebase architecture (from cllm.h):
- **Weights/embeddings/parameters**: double* (higher precision)
- **Temporary computations**: Can use float* for performance
- **Activations/gradients**: Should match weight precision (double*)

The fix strategy:
1. Change temporary float* variables to double* when they point to model parameters
2. Keep float* for truly temporary computation buffers
3. Fix function signatures to accept double* where needed
4. Remove unused functions
5. Fix address comparison warnings
